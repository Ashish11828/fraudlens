# FraudLens

An accessibility-first scam prevention web app for a 600 × 600 Meta Ray-Ban Display preview. Includes guided scam checks, practice scenarios, pressure cards, accessibility preferences, and browser read-aloud support.

## Recovered version

This copy was recovered from https://scamfruadlens.netlify.app/ on 2026-10-24 at the project owner's request. It preserves the deployed HTML, CSS, and JavaScript. Original development files and Git history were not available.

## Run locally

Use a static web server with a fallback to index.html for client-side routes. For example, with Node.js installed:

```sh
npx serve -s .
```

Open the local URL printed by the server. Netlify deployments can use the included _redirects file. No build step is required.

## Controls

Use the visible buttons, Enter / Left for Yes, Right / Down for No, and Escape to return home. Accessibility preferences are stored in the browser.
